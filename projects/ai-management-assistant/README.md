# AI Management Assistant
### 경영관리 업무 자동화 PoC

## 프로젝트 소개

경영관리 업무는 매주·매월 비슷한 흐름이 반복됩니다. 자료를 취합하고, 숫자가 바뀐 부분을 찾고, 원인을 확인하고, 보고 문장을 다시 정리하는 과정입니다.

이 프로젝트는 그중 사람이 매번 반복해서 하는 부분을 줄일 수 있을지 생각하면서 만든 PoC입니다.

핵심은 **AI가 숫자를 대신 만드는 것**이 아니라, 기존 데이터와 계산 결과를 바탕으로 사람이 확인해야 할 부분을 먼저 정리해주는 것입니다.

## 자동화 대상으로 본 업무

- 사업부별 매출·원가·수주 자료 취합
- 전주 / 전월 대비 변동 확인
- 목표 대비 Gap이 큰 항목 표시
- 주요 프로젝트 변동사항 요약
- 추가 확인이 필요한 내용 정리
- 보고용 문장 초안 작성

## Workflow

1. 원본 데이터 업데이트
2. 누락값과 이상 변동 확인
3. 주요 KPI 변화 추출
4. AI가 보고 초안 생성
5. 담당자가 숫자와 문장 확인
6. Follow-up 항목 정리

## 설계할 때 중요하게 본 점

### 1. 숫자는 기존 로직으로 계산

매출, 원가, 수주, 목표 대비 차이 같은 수치는 기존 Excel/Python 로직을 사용합니다. 생성형 AI가 숫자를 임의로 계산하거나 만들어내지 않도록 역할을 분리했습니다.

### 2. AI는 정리와 초안에 사용

AI는 숫자 변화의 의미를 정리하거나 보고 문장을 만드는 데 사용합니다. 최종 보고 전에 사람이 다시 확인하는 구조를 기본으로 봤습니다.

### 3. 결과의 근거를 확인할 수 있게 구성

예를 들어 "매출이 감소했다"는 문장이 나오면 어떤 사업부 또는 프로젝트의 숫자가 변했는지 다시 확인할 수 있어야 한다고 생각했습니다.

## Assistant 예시

```text
이번 주 확인 포인트

- 예상 매출 변동이 큰 프로젝트 우선 확인
- 수주 확도 하락 건의 원인과 다음 액션 확인
- 장기 재고·채권 처리 일정 업데이트
- 목표 대비 Gap이 큰 사업부 별도 확인
```
