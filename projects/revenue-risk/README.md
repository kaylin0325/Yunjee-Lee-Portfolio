# 매출 달성 리스크 분석
### Revenue Risk Analysis

## 프로젝트 소개

경영관리 업무를 하면서 예상실적을 볼 때 가장 어려웠던 점은, 숫자가 잡혀 있다고 해서 그 금액이 그대로 실적이 되는 것은 아니라는 점이었습니다.

프로젝트마다 수주 진행상태가 다르고 실제 매출이 인식되는 시점도 달라서, 단순 합계보다 **이번 분기에 실제로 들어올 가능성이 어느 정도인지**를 구분해서 보는 게 필요했습니다.

그래서 프로젝트별 확도와 매출 인식 계획을 기준으로 실적 가능 범위를 나누고, 금액 영향이 큰 리스크 프로젝트를 먼저 볼 수 있도록 정리했습니다.

## 분석 기준

- 프로젝트별 계약/예상 금액
- 수주 확도 및 진행상태
- 매출 인식 예정 월
- 분기 내 인식 가능 여부
- 목표 대비 예상 실적

프로젝트는 확도와 인식 가능 시점을 같이 보고 Low / Medium / High Risk로 구분했습니다.

## 분석 예시

분석 대상 신규수주 467억을 기준으로 보면,

- 확정 가능: 183억 (39%)
- 가능 건 포함 Max Case: 415억 (89%)
- 분기 내 인식이 어렵거나 위험한 금액: 52.2억

단일 예상실적 하나를 만드는 대신 **확정 Case와 가능 Case를 나눠서 목표 달성 범위를 보는 방식**으로 구성했습니다.

## 분석 흐름

1. 프로젝트별 금액, 확도, 매출 인식 월 정리
2. 분기 내 매출 인식 가능 여부 확인
3. 확정 / 가능 / 위험 프로젝트 분류
4. Scenario별 예상실적 계산
5. 금액 영향이 큰 Risk Project 우선 확인
