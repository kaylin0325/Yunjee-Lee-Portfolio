# Weekly Insight Dashboard

Excel 기반 주간 사업회의 데이터를 시각화하는 대시보드의 포트폴리오용 UI 데모입니다.

## 구성

- 현황판: 예상 수주, 실행계획, 달성률, 전주 대비
- Opportunity: 신규 사업 기회 요약
- 유지보수: 갱신 대상·착수·완료 현황
- 매출: 월별 계획과 예상 매출 비교
- 월간/분기/연간, 사업부, 담당자 필터 UI

## 데이터 보호

이 공개 버전에는 실제 회사명, 고객명, 프로젝트명, 계약금액 또는 원본 Excel 데이터가 포함되어 있지 않습니다. 화면에 표시되는 값은 레이아웃 시연을 위한 익명 샘플 데이터입니다.

## 실행
